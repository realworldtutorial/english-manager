## 🕐 Giờ 1: Làm quen Nuxt 3 + Khởi tạo Project

### ✅ Nội dung
- Tổng quan Nuxt 3 và sự khác biệt so với Vue 2
- Cài đặt Nuxt 3 project
- Xem cấu trúc thư mục mới

### 🚀 Thực hành
```bash
npx nuxi init nuxt3-playground
cd nuxt3-playground
npm install
npm run dev
```
